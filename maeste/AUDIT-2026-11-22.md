# MaEste — audit (2026-11-22)

A vizsgálat hatóköre a `maeste/` HTML/CSS/JavaScript kliens. A külön hosztolt API szerveroldali biztonsága, jogosultságai és adatbázisa innen nem ellenőrizhető.

## Prioritásos hiányosságok

| Prioritás | Megállapítás | Javítás / elfogadási kritérium |
| --- | --- | --- |
| P0 | Nincsenek automatizált E2E tesztek és CI. | Playwright smoke tesztek a belépés, keresés, 3 szavazás, undo, könyvtár és páros szoba folyamataira; sikeres CI. |
| P0 | Az API külön hosztolt, szerveroldali audit nem történt. | Jogosultságok, rate limit, versenyhelyzetek és adatkezelés vizsgálata backend-hozzáféréssel. |
| P1 | A CSS több mint 8 000 soros, egymást felülíró animációs szabályokkal. | CSS modulok, egyetlen végleges animációdefiníció, vizuális regressziós teszt. |
| P1 | Az animáció minden képkockán ellenőrizte a DOM-állapotot. | 100 ms-os ellenőrzés és eseményalapú leállítás. **Most javítva.** |
| P1 | A szavazás az API-mentésre vár az animáció előtt. | Azonnali visszajelzés és biztonságos visszaállítás hálózati hibánál. |
| P1 | A három mozgás nem mindenhol egyenletes. | Kompozitoros transform/opacity animációk; csökkentett mozgás tiszteletben tartása. **Most finomítva.** |
| P1 | HTML-template-ek külső adatokkal és URL-ekkel. | XSS- és URL-validációs tesztek, HTTPS URL-ek engedélyezése. |
| P2 | Egyetlen nagy, 1 213 soros app.js. | API/állapot/UI/szoba/könyvtár modulokra bontás. |
| P2 | Nincs hitelesített fizikai mobilos FPS-mérés. | Safari/Chrome profilozás alacsony teljesítményű eszközön. |

## Jelen módosítások
- `Most nem`, `Már láttam`, `Jöhet`: finomított kilépő animációk.
- Folyamatos frame-ellenőrzés helyett 100 ms-os kontextusfigyelés.
- Frissített CSS/JS cache-verzió.

## Ellenőrzés
- `node --check maeste/app.js`: sikeres.
- `node --check maeste/backup.js`: sikeres.
- `git diff --check`: sikeres.
- Valós mobilos FPS, hitelesített end-to-end és szerveroldali biztonsági tesztek: **nem készültek el**.

## Következő sorrend
1. Automatizált smoke és hibás hálózati tesztek.
2. Mobilos FPS-mérés és finomhangolás.
3. Backend-hitelesítés és adatbiztonsági audit.
4. CSS/JS refaktor regressziós tesztekkel.
